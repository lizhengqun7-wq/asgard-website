基本能力值

STR

表示「strength:力量、強壯」。

STR如字面所示，與物理攻擊力和道具負重有關。

關於負重上限，每1點STR會增加2點Weight。但裝備品附魔的STR不會增加。

其中對攻擊力的影響比較複雜，分為以下要素。

1.　基本傷害

以疊加在武器攻擊力上的方式，依STR值提高「根本」的傷害。

(但是修道士適用的不是STR而是CON的值。)

另外，戰士・修道士・騎士的基本傷害還會再加上「STR加成」。

2.　無視防禦傷害

基本傷害會受到對方防禦力(AC)影響，

但另外還存在不論防禦力為何都能造成固定傷害的加成值。

這個會隨STR提升而增加。

這項要素和基本傷害不同，修道士也一樣適用。

3.　技能傷害

技能攻擊力會隨技能等級和STR值增加。

4.　技能成長率

提高STR後，有技能等級的攻擊會比較容易升級。

和有相同效果的DEX相比，只能得到大約一半的效果。

上述的意思就是「只要STR點高，不管裝備是什麼，攻擊力都會變高」。

(也可以充分利用高威力武器和HIT・DAM補正來提高攻擊力。)

這些要素也反映在怪物的基本攻擊上。

DEX

表示「dexterity:靈巧、敏捷」。

DEX雖然不起眼但重要度很高，會一點一點地牽涉到各種要素。

1.　命中率

DEX高的話，直接攻擊的命中率會提高。

命中率夠高的狀態下，比較容易發生暴擊(威力２倍)，

可以說對提升攻擊力也有幫助。

此外，盜賊的DEX對命中率的影響被設定得比其他職業高。

2.　迴避率

提高DEX的話，敵人的近距離攻擊變成「MISS」的機率會提高。

而且降低敵人的命中率，也就代表被暴擊的機率會降低。

此外，盜賊只對正面的敵人，DEX對物理攻擊迴避率的影響力才會變高，

對魔法攻擊迴避率也有些許影響。

3.　技能成長率

提高DEX後，有技能等級的攻擊會比較容易升級。

4.　其他

一部分特殊技能(毒擊或胡椒炸彈等)的命中率會提高。

沙塵炸彈的攻擊力也會受到影響。

另外，STR與DEX的搭配會讓物理攻擊力獲得(雖然只有一點點的)加成。

如果說STR關係到殲滅力高低帶來的成長速度提升，

那DEX就是增加面對較強敵人時的穩定感與持久力的要素。

對於近身攻擊敵人類型的角色來說，要加到什麼程度、期待什麼樣的效果，

依想法不同而展現個性，是個有趣的能力值吧。

CON

表示「constitution:體格、體質」。

CON主要與耐打程度有關。

1.　HP・SP最大值上升率

角色升級時「HP・MP・SP」的最大值會上升，

其中HP・SP的上升量與CON有關。

CON越高，升級時的上升量就越多。

不過上升量是以「基本等級與基本CON的差」計算，

所以在自己等級已經相當高的狀態下才把點數加到CON，

並不會有太大的影響。

如果想培養HP・SP高的角色，

就要有一開始戰鬥會稍微辛苦的心理準備，

需要在一定程度上連續把點數分配給CON。

2.　HP・SP自然回復量　(維持最大自然回復量：CON>=Lv+10)

角色停在原地一段時間後，HP・SP會自然回復。

此時增加的量會依基本等級與CON的差而增加。

這個和1.不同，裝備的補正也有效，

所以即使點數加在其他能力值上，也能維持最高效率的回復量。

3.　減輕異常狀態

受到毒或火等持續造成傷害的魔法時，

可以減少傷害量或縮短效果時間。

(但是無法降低魔法本身的命中率。)

4.　其他

只有修道士，提高CON也會讓基本攻擊力上升。

而且氣彈系遠距離攻擊的威力也會提升。

CON對HP・SP最大值上升率有恆久的影響，

所以如果不從前期就集中分配點數，就無法發揮太大效果。

維持初始值也完全可以玩下去，

但如果要加點，在初期集中投入很重要。

INT

表示「intelligence:知能、智力」。

INT關係到魔法性能的提升。

1.　魔法攻擊威力上升

提高INT可以提升標準攻擊魔法的威力。

和STR或DAM不同，INT帶來的上升率呈二次函數成長，

特別是魔術師，在高等級時能獲得很大的好處。

2.　HP回復魔法回復量增加

包含自我治療在內的回復系魔法中，HP的回復量受等級與INT影響。

在敵人強大的區域常常會被一擊造成大量傷害，

為了讓回復量跟得上，把點數加到INT也是選擇之一。

3.　持續性支援魔法時間延長

部分支援魔法(神聖之手等)，提高INT後持續時間會延長。

對於效果高但持續時間短的支援魔法，

考量到消耗MP、交戰時間與效果結束的時機，

為了補足這點，可能會有提高INT的必要。

就像直接戰鬥職業的STR一樣，以魔法攻擊為主軸的類型INT很重要。

不過由於幾乎沒有防禦方面的好處，越到後期「不是你死就是我亡」的情況會越明顯。

如果期待輔助效果，與其分配能力點數，更推薦用裝備來調整。

WIS

表示「wisdom:智慧、賢明」。

如果說INT關係到魔法的威力，

那WIS就是有助於提升魔法好用程度的能力值。

1.　MP最大值上升率

就像CON影響升級時HP・SP最大量的增加一樣，

提高WIS後，升級時MP最大值的增加量會變多。

增加率的傾向也和CON相同，等級越早投入點數，

效果量的差異就越明顯。以直接攻擊為主就加CON，

以魔法(回復・援護)為主就加WIS，

這樣各個角色的大致傾向自然就會決定下來。

2.　MP自然回復量　(維持最大自然回復量：WIS>=Lv+10)

這點也和CON相同，會依與等級的差而增加隨時間自然回復的MP量。

MP和HP・SP不同，即使在進行攻擊等行動，也一定會在固定時間內回復固定量，

所以只要WIS高於等級，就一定能帶來很大的效果。

3.　SP回復魔法回復量增加

INT會增加HP的回復量，而WIS可以增加SP的回復量。

特別是在殲滅力重要的等級80左右之前，

持續強化WIS就能獲得很大的支援效果。

4.　魔法攻擊迴避率

對於直接的打擊攻擊，提高DEX可以增加迴避率，

對於魔法攻擊，提高WIS就能增加迴避率。

不過魔法攻擊本身的命中率基本上偏高，依攻擊方向的命中率補正也不像打擊那麼大，

所以除了投入大量點數的聖職者等以外，可能不太能感受到效果。

(異常狀態系魔法本身是用WIS迴避，但中招之後的效果減輕則依賴CON。)

WIS在魔法相關攻防時，發揮的是類似直接攻擊時CON與DEX兼具的效果。

由於怪物的遠距離攻擊幾乎全都算作魔法，所以在培養以支援為主的聖職者等情況下，

作為「誘餌」一手承受這些攻擊，同時確保能掩護數名前衛的MP，

重視WIS可說是定石。

其他能力值

AC

表示角色、怪物物理防禦力的數值。

AC100的狀態下承受100%的物理傷害，每降低AC-1就減輕0.5%物理傷害。

最多可降到AC-100，但存在不依賴AC的無視防禦傷害，

即使在AC-100的狀態下也會受到無視防禦傷害。

一般角色在沒有裝備的狀態下是AC100。

可以藉由穿戴防具、使用輔助魔法、技能來降低。

只有修道士會依CON與等級獲得AC加成。

MC

表示角色、怪物魔法防禦力的數值。基本上與AC相同。

MC100的狀態下承受100%的魔法傷害，每降低MC-1就減輕0.5%魔法傷害。

最多可降到MC-100，但存在不依賴MC的無視防禦傷害，

即使在MC-100的狀態下也會受到無視防禦傷害。

不過魔法的無視防禦傷害被設定得比物理攻擊低很多。

一般角色在沒有裝備的狀態下是MC100。

可以藉由穿戴防具、使用輔助魔法、技能來降低。

修道士會依CON與等級獲得MC加成。

聖職者與吟遊詩人會依WIS獲得MC加成。

AAR

表示角色、怪物物理迴避率的數值。

AAR越高越容易迴避物理攻擊，也越不容易受到暴擊。

因為是對原本由DEX與等級決定的迴避率做比例上升，

據說DEX越高的角色受益越大，但詳情不明。

也有可能只是單純加算在DEX與等級決定的迴避率上。

一般角色在沒有裝備時AAR為0。

可以藉由防具、輔助技能魔法提升。

SAR

表示角色、怪物魔法迴避率的數值。

SAR越高越容易迴避遠距離攻擊及異常狀態。（部分例外）

因為是對原本由WIS與等級決定的迴避率做比例上升，

據說WIS（盜賊還有DEX）越高的角色受益越大，但詳情不明。

也有可能只是單純加算在WIS與等級決定的迴避率上。

一般角色在沒有裝備時SAR為0。

可以藉由防具、輔助技能魔法提升。

只有魔術師會因為加INT而獲得SAR加成。

DAM

表示角色物理攻擊追加傷害的數值。

物理攻擊時傷害會增加DAM的數值。

例：DAM0時造成1000傷害的攻擊，DAM10的話會變成1100傷害

對魔術師的攻擊魔法也有效果，當攻擊魔法與勳章的屬性一致時同樣會增加傷害。

可以藉由裝備、輔助技能魔法提高。

HIT

表示角色物理攻擊命中率的數值。

HIT越高物理攻擊越容易命中，也越容易出現暴擊。

因為是對原本由DEX與等級決定的命中率做比例補正，

據說DEX越高的角色HIT的影響也越大，但詳情不明。

也有可能只是單純加算在DEX與等級決定的命中率上。

只限盜賊，所分配的參數每Dex10會額外加算Hit1。(捨去尾數)

可以藉由裝備補正、輔助技能魔法提高。

MDAM

與魔法專用的DAM效果相同。

MHIT

與魔法專用的HIT效果相同

WEIGHT

表示角色可持有重量的數值

以目前持有重量/最大持有重量顯示。

初始狀態（STR3、Lv1）為78，升級+2，每分配STR1就+2。

只有戰士與騎士，每STR10有Wei+5的加成。

戰士與騎士的計算式：　Weight = 70 + Lv×2 + Str×2 + (RoundDown(Str/10))×5

戰士與騎士以外的計算式：　Weight = 70 + Lv×2 + Str×2

RAC

每RAC1減輕遠距離物理攻擊傷害1%。

藉由天上服的升級來附魔。效果尚未實裝。

ADDown

每ADDown1減輕物理攻擊傷害(近距離・遠距離兩者)1%。

藉由天上帽子的升級來附魔。效果已實裝。

AtkSPEED

攻擊速度提升？詳情不明。也有附魔為ASD的情況。AskSPEED與ASD是否相同不明。

藉由天上脛甲的升級來附魔。效果尚未實裝。
