【官方公告】

感謝您平日對『神之領域』的愛護。

今天的定期維護進行了以下變更。

・更新至版本2.691

用戶端版本將變為「2.681→2.691」。

2.691完整用戶端(2.20GB）

2.681→2.691手動修補檔(163MB）

・新增新職業「預言者」與預言者的城鎮「艾德安德」

・新增艾德安德任務

・新增任務「任務手冊」

※隨著任務手冊實裝，獎勵道具升級。

【日程】

11月19日（三）～12月24日（三）

・舉辦「預言者培育活動」。

【舉辦日程】

11月19日（三）～12月10日（三）

【內容】

建立新職業「預言者」，並在期間內達到一定等級的使用者，

將抽選贈送NEXON POINT。

【獎品】

NEXON POINT

・Lv50以上：2000Point（10名）

・Lv20以上：500Point（20名）

※Lv50以上的使用者也是500Point的抽選對象。

・舉辦「師父救命啊！」活動。

【舉辦日程】

11月19日（三）～12月10日（三）

【內容】

結成師徒關係，協助徒弟進行任務「任務手冊」，

就能取得獎勵。

(1) 與活動期間內建立的角色結成師徒關係。

(2) 使用徒弟的任務手冊[初級]，通關其中記載的任務10個以

上。

(3) 師父向位於盧亞斯王宮前的活動NPC「艾爾妲」報告，就能

取得獎勵。

【注意事項】

師父向NPC「艾爾妲」報告之前，若徒弟先向各職業城鎮的NPC「安德烈」

報告，就無法領取獎勵。請務必先向NPC「艾爾妲」

報告。

【褒賞】

各種附魔捲軸或師父之證（全能力值+1、HP/MP/SP+5、

使用期限：3日）

※可取得的獎勵為隨機。

・變更傷害顯示

・新增魔王、對人HP顯示

・新增櫻花村傳送門

・新增櫻花村傳送門用媒介

・新手任務（品奇歐任務）改版

・新增備忘錄的一次刪除功能

※使用「Ctrl」「Shift」即可一次刪除。

・商城新增以下道具

套組彩券[預言者公開紀念]：980Point

神祕寵物培育組：1000Point

新手彩券：90Point

※新增預言者的裝備及道具20種

・商城的以下道具打折。

經驗加成[1次]：500Point⇒450Point

經驗加成[7天]：700Point⇒560Point

名聲加成[1次]：350Point⇒300Point

名聲加成[7天]：490Point⇒400Point

・修正遊戲內說明（F1說明）

・修正寵物留言一覽

神之領域營運團隊

自2008年8月7日起，規格變更為需要關聯NEXON ID

  • 2008年8月7日起新角色需要關聯NEXON ID
  • 2008年10月8日11點前未關聯NEXON ID的既有角色將無法登入遊戲
    上述關聯期限延長至2008年11月5日11點
    ※使用商城時，登入的NEXON ID會自動被關聯
    ※10月8日以後似乎也能在關聯頁面進行NEXON ID關聯後登入
  • 一旦進行過關聯的NEXON ID無法變更
  • 每個NEXON ID在各伺服器最多可登錄30個角色
    因此持有30個以上角色的使用者必須一人取得多個NEXON ID
