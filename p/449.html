關於技能・魔法

近距離攻擊

  • 克萊茲
  • 最先能習得的技能。
  • 菲亞克萊茲取得條件是SLv10或Lv21，所以容易從技能等級制取得。
  • 取得菲亞克萊茲後，請優先鍛鍊那個。
  • 克里斯克萊茲
  • 費爾克萊茲
  • 比克萊茲更強的技能。
  • 取得丘歐克萊茲後，請優先鍛鍊那個。
  • 丘歐克萊茲
  • 比菲亞克萊茲更強的技能。
  • 取得圖尼戴爾後，請優先鍛鍊那個。
  • 跟隨戴爾
  • 轉職時支給的技能，比丘歐克萊茲更強。
  • 即使提升之前的技能也無法取得本技能，
  • 要注意從本技能衍生的是融化戴爾，不會衍生到圖尼戴爾。
  • SLv45(Lv71)取得融化戴爾後，也有作為連擊使用的價值。
  • 提納因戴爾
  • 是正面3個方向範圍技能，使用混合藥水可單體連打。
  • 和戰士的一字斬一樣，從所有被攻擊命中的敵人獲得技能經驗值。(其他範圍技能也一樣)
  • 一般在SLv55(Lv85)取得卡塔爾鐮刀後就沒必要培養，
  • 但連打卡姆爾索馬會頭暈的人，繼續使用圖尼戴爾也是一個辦法。
  • 相當勉強地在Lv35左右習得的話，SP消耗可能很吃緊。
  • 以SLv為目標習得融化戴爾・卡姆爾索馬的情況
  • 單體攻擊的跟隨戴爾和融化戴爾，與範圍攻擊相比技能等級較難提升。
  • 好用的範圍技能雖然有魅力，但建議在連擊中混入單體技能使用。
  • 以Lv習得融化戴爾・卡姆爾索馬的情況則不在此限。
  • 梅爾特因戴爾
  • 無法用混合藥水連打(延遲1)的技能。
  • 提升SLv時，與跟隨戴爾或卡塔爾鐮刀交替連擊很有效。
  • SLv42可以學會卡姆爾索馬。
  • 夾在卡姆爾索馬和阿斯蘭鐮刀之間，可預期對正面敵人造成大傷害。
  • 卡姆爾索馬
  • 有2～3秒等待時間，是阿斯蘭鐮刀的發動條件技能。
  • 使用後的等待時間中，輔助圖示欄會出現圖示。
  • 作為SP使用型對正面技能是最強的。
  • 但是因為等待時間的關係，無法2種交替連擊。需要另外使用1～2種技能。
  • 卡塔爾鐮刀
  • 因混合藥水而無法連打的正面3個方向範圍攻擊技能。
  • 雖然在旋轉，但無法攻擊後方。
  • 時鐘迪卡普馬
  • 不只消耗SP，還會消耗約最大HP一半，是對正面攻擊最強等級的技能。等待時間18秒。
  • 與修道士的殲滅擊不同，不是必中，有失誤/暴擊判定。
  • 攻擊力高度依賴HP消耗量，HP越高的阿修羅越能發揮威力。
  • 雖然也取決於DAM・STR，但考慮HP依存部分的話只是誤差等級。
  • 不必HP全滿也能發動，所以剩餘HP 4～5成時也可使用。
  • 不過HP不會低於1，剩餘HP低於原本消耗量時，
  • HP消耗量會減少，所以與同角色HP全滿時相比攻擊力會下降。
  • 因為HP不會低於1，光憑本技能不會死亡，但被敵人攻擊而死亡的可能性很高。
  • 阿斯蘭鐮刀
  • 全方位範圍攻擊技能。連背後敵人的目標也會拿到，要注意是把雙面刃。
  • 必須先使用卡姆爾索馬，有點像修道士的冥幻之型的感覺。
  • 和修道士的「獄衝打」一樣沒有暴擊判定，屬性倍率有加成，具有特殊的性質。
  • 和對等屬性時的傷害計算相比，善惡勳章時傷害算得更高，
  • 沒有勳章時傷害算得更低。
  • 幾乎不受方向修正影響，似乎只反映攻擊傷害的部分。
  • （方向修正取決於對象與自己的朝向，如果只看位置關係會看錯）
  • 阿爾尼斯鐮刀
  • 進入德爾克雷維斯後可習得的技能之一。
  • 可同時攻擊正面5個方向的範圍技能。是阿斯蘭鐮刀的上位……不如說是卡塔爾鐮刀的上位攻擊技能。大概是因為威力與範圍都變強了，需要1秒的蓄力動作。

遠距離攻擊

  • 阿克艾提斯
  • 阿修羅能取得的第一個遠距離攻擊。
  • 不是必中，作為拿目標用不可信賴。
  • 尤蘭艾蒂斯
  • 阿克艾提斯的多段HIT魔法。
  • 一次詠唱，會打出2道衝擊波。
  • 第1發命中後，才打出第2發。(也有2發幾乎同時打出的時候)
  • 第1發與第2發的間隔是隨機的。已確認至少有3種間隔。
  • 第1發沒命中的話第2發不會發動。
  • 第2發MISS的情況也會有動作。第1發MISS的情況，不會有第2發的動作。
  • 比阿克艾提斯大一圈的圖像。
  • 卡普蘭艾蒂斯
  • 3段HIT魔法。與尤蘭艾提斯一樣，每次1發共打出3次衝擊波。
  • 與尤蘭艾提斯相同，第1發沒命中的話第2、3發不會發動。第2發以後也一樣。
  • MISS的話，之後的動作不會出現，
  • 第2發以後的間隔是隨機的這點也與尤蘭艾提斯相同。
  • 比尤蘭艾提斯再大一圈的圖像。
  • 圖林塔艾提斯
  • 3段HIT魔法。性質與圖像和卡普蘭艾提斯相同。
  • 與實裝當初相比不知不覺被弱化了。
  • 消耗:MP230→150，威力:卡普蘭艾提斯的約2倍→約1.5倍

輔助

  • 奈拉
  • 自身AC-10。
  • 最先能學會的輔助技能。
  • 對防禦力低的阿修羅來說可能是生命線之一。
  • 雖然只是AC-10，但AC-10還是AC-10。
  • 賦格
  • 自身DAM/HIT+8。
  • 可以提升物理攻擊力與命中率。
  • 直到能習得特萊恩的Lv90為止都會一直使用，所以會長期受到照顧。
  • 可與其他職業的輔助技能・魔法重複。
  • 維克拉
  • 增加敵方對象的物理/魔法傷害。
  • 是否減少ADD/MDD，因為狀態分析不會顯示所以不明。
  • 現在是只能從拼圖方塊或露妮雅的捲軸取得的稀有魔法。
  • 菲拉
  • 自身AC-20、MC-10。
  • 奈拉的上位輔助。這個與奈拉不能疊加。
  • 也不能與神聖護體重複。
  • 除了AC外，雖然不起眼，也能強化MC。
  • 菲亞爾
  • 每秒自身HP回復10。
  • 雖然回復量微不足道，但和AC/MC強化技能一樣可能成為生命線。
  • 可與生命力恢復術或尼特拉斯治癒重複。
  • 賽斯
  • 自身AAR+10%。
  • 物理迴避率稍微上升。
  • 也可與其他職業的輔助疊加。
  • 安特拉
  • 自身的異常狀態抵抗率+20%。
  • 可以稍微迴避異常狀態。
  • 實際上看起來沒什麼效果。
  • 蓋特
  • 對自身產生連擊效果。
  • 阿修羅版的覺醒，也就是混合藥水。
  • 在戰鬥對決中也能充分發揮的強力輔助。
  • 達姆德
  • 自身AC-25、MC-15
  • 強化菲拉的輔助。
  • 不能與奈拉和菲拉疊加。
  • 也不能與神聖護體重複，所以不想提升MC的話需要事先自我申報。
  • ※不過，如果對方願意併用魔法護盾群組，理論上神聖護體(AC-40）＋魔法護盾群組
  • （MC-15)比較強。
  • 特萊因
  • 自身DAM/HIT+15%。
  • 富加的上位輔助技能。
  • 不能與富加疊加。
  • 在沒有缺點地提升物理攻擊力/命中率的輔助中是最上位。
  • 阿克拉內特
  • 使用國王之心可以習得。
  • ADD/MDD減少。
  • 維凱拉的上位輔助。不能與維凱拉疊加。
  • 可使敵方對象的物理/魔法傷害增加。
  • 因為是狀態分析無法顯示的能力值，實際ADD/MDD是否減少不明。
  • 可與夢饜的詛咒或夢饜的箴言疊加。
  • 不取決於WIS，而是一定機率的命中率，所以習得的話殲滅力會稍微上升。
  • 西拉圖
  • 進入德爾克雷比斯後可習得的技能之一。
  • 自身AAR+25%。
  • 賽斯的上位輔助，不能與賽斯疊加。
  • 克拉夫馬加
  • 進入德爾克雷維斯後可習得的技能之一。
  • 自身AC+8、DAM/HIT+20%。
  • 物理攻擊力/命中率比特萊恩提升更多，但代價是物理防禦力下降。
  • 是特萊恩的上位輔助，所以不能疊加。
  • 潘圖拉
  • 進入德爾克雷維斯後可習得的技能之一。
  • 自身AC+30、DAM+35%、HIT+10%。
  • 可獲得超越克拉夫馬加的物理攻擊力。代價是會失去驚人的物理防禦力。
  • 因為是克拉夫馬加、特萊恩的上位輔助，所以無法疊加，真是捨身的輔助。

天上

  • 拉克修[善]／修里[惡]
  • 令人期待的天上一次技能。
  • 說明文是攻擊命中的話一定機率上升攻擊速度這種技巧型輔助，但實際上是普通的攻擊技能。
  • 子彈業力[善]／突擊業力[惡]
  • 天上二次技能。
  • 與時鐘迪卡普馬一樣，消耗HP對自己前方的目標造成大傷害。
  • ※HP消耗也是兩倍份。
  • 自己的HP越接近最大值，造成的傷害越增加這點也與時鐘迪卡普馬相同。
  • 是一發逆轉、雙面刃的技能(不過現在對怪物會當客戶端，有bug，所以用途微妙)。
  • 另外，角色面向方向的判定範圍是前方以及左方或右方。
  • (左右哪一邊是否依某些條件改變？)
  • 技能經驗值只有前方一格？

技能鍛鍊與連招指南

首先請熟讀基礎知識，記住基本的事。

  • 取得克萊茲(Lv5)～取得菲亞克萊茲(克萊茲SLv10或Lv21)
  • 克萊茲
  • 取得菲亞克萊茲～取得丘歐克萊茲(菲亞克萊茲SLv23或Lv41)
  • 費爾克萊茲
  • 取得丘歐克萊茲～取得圖尼戴爾(丘歐克萊茲SLv35或Lv65)
  • 丘歐克萊茲
  • ※戴爾系名稱雖然相似，但從跟隨戴爾不會衍生圖尼戴爾。
  • 只是使用時的動作相同而已，要注意。
  • 習得圖尼戴爾後才第一次能發出範圍攻擊。
  • 取得圖尼戴爾～取得卡塔爾鐮刀(圖尼戴爾SLv55或Lv85)
  • 圖尼戴爾(鍛鍊融化戴爾時交替連擊)
  • 取得卡塔爾鐮刀～取得阿斯蘭鐮刀(卡塔爾鐮刀SLv50或Lv95)
  • 卡塔爾鐮刀→圖尼戴爾或融化戴爾
  • ※理論上能發動阿斯蘭鐮刀的一般等級最短是習得卡塔爾鐮刀
  • 因前提條件圖尼戴爾SLv而成為Lv55，但發動阿斯蘭鐮刀的條件
  • ——習得卡姆爾索馬的技能是Lv51～，需要相當的努力。
  • 取得跟隨戴爾(Lv51)～取得融化戴爾(跟隨戴爾SLv45或Lv71)
  • 跟隨戴爾
  • 取得融化戴爾～取得卡姆爾索馬(融化戴爾SLv42或Lv85)
  • 融化戴爾→跟隨戴爾或圖尼戴爾或卡塔爾鐮刀
  • 取得卡姆爾索馬～取得時鐘迪卡普馬(卡姆爾索馬SLv48或Lv91)
  • 卡姆爾索馬→(融化戴爾→)圖尼戴爾或卡塔爾鐮刀
  • ※卡姆爾索馬使用後的等待時間長，所以在能打下一次卡姆爾索馬之前使用2～3發其他技能。
  • 取得阿斯蘭鐮刀＆卡姆爾索馬
  • ・基本連擊
  • 卡姆爾索馬→卡塔爾鐮刀→阿斯蘭鐮刀(→卡塔爾鐮刀)
  • ・僅前3方向範圍攻擊
  • 卡塔爾鐮刀→圖尼戴爾
  • ・重視正面＋前3方向範圍攻擊
  • 卡姆爾索馬→卡塔爾鐮刀→圖尼戴爾→卡塔爾鐮刀
  • ※為了避免因阿斯蘭鐮刀拿到背面敵人目標的基本連擊變體。
  • 與連打卡塔爾相比，正面敵人的殲滅速度較快，但對前3方向的總傷害會下降。
  • ・以攻擊正面為主＋範圍攻擊
  • 卡姆爾索馬→融化戴爾→阿斯蘭鐮刀或卡塔爾鐮刀→融化戴爾
  • ※將上述連擊進一步重視正面。斜前2方向的目標較難拿到。
  • ※赫爾西昂女王討伐中這個連擊最有效。不過，限於左右會打到其他玩家的情況。
  • ・僅單體攻擊
  • 卡姆爾索馬→融化戴爾→跟隨戴爾(→融化戴爾)
  • ※用於在模式城堡2等進行範圍攻擊有PT團滅之虞時，或
  • 使用範圍技能會拿到超過能承受極限的目標時。
  • 總傷害下降是難免的，對正面的殲滅力也會下降是缺點。
  • 最好避免在臨時PT只使用這個連擊。
  • ※赫爾西昂女王討伐中，上述以正面為主＋範圍攻擊連擊在左右不是其他玩家時，
  • 不是一點集中砲火而打到不能打的部位的情況下，這個連擊才有效。
  • ※途中考慮自己HP・等待時間，穿插時鐘迪卡普馬會很有效。
